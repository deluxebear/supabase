## Verified 0.2.8 facts used by this plan

From `/tmp/pgd-up` at `v0.2.8`:

- `df.version()` returns `"0.2.8 (built <timestamp>)"`, not a bare semver. **Capability gating
  uses `pg_extension.extversion` (`installed_version`)**, because the available SQL surface is
  determined by the installed extension schema, not the binary. `log_workflow_sql` availability
  is "GUC readable" (`current_setting(..., true) IS NOT NULL`).
- Node `query` shapes (`src/dsl.rs`):
  - `SQL`: raw SQL text.
  - `SLEEP`: seconds as text, e.g. `"10"`.
  - `SIGNAL`: `{"signal_name": "...", "timeout_seconds": n | null}`.
  - `WAIT_SCHEDULE`: `{"cron_expr": "..."}`.
  - `HTTP`: `{"url","method","body","headers","timeout_seconds"}` (`headers` object or null).
  - `HTTP_MULTIPART`: `{"url","method","parts","headers","timeout_seconds"}`.
  - `BREAK`: `{"break_value": string | null}`.
  - `IF` (`df.if`): `left_node` = then, `right_node` = else, `{"condition_node": "<id>"}` in query.
  - `IF` (`df.if_rows`): `left_node` = then, `right_node` = else,
    `{"condition_type": "result_has_rows", "result_name": "..."}`.
  - `LOOP`: `left_node` = body; query may hold `condition_node` and/or
    `"continue_on_failure": true`; query may be NULL for a plain loop.
  - `JOIN`: left, right, optional `{"extra_nodes": [...]}`. `RACE`: left, right.
  - `THEN`: left, right.
- Child walk order in `src/node_status.rs`: IF → condition, then, else; LOOP → body, condition;
  JOIN → left, right, extras.

```ts
export type DurableCapabilities = {
  multipart: boolean
  transactionMode: boolean
  loopContinueOnFailure: boolean
}

function parseVersion(version: string | null | undefined) {
  const match = version?.trim().match(/^(\d+)\.(\d+)\.(\d+)/)
  return match ? [Number(match[1]), Number(match[2]), Number(match[3])] : null
}

export function compareDurableVersions(a: string, b: string) {
  const left = parseVersion(a)
  const right = parseVersion(b)
  if (!left || !right) return null
  for (let i = 0; i < 3; i++) if (left[i] !== right[i]) return left[i] - right[i]
  return 0
}

const atLeast = (version: string | null | undefined, minimum: string) =>
  !!version && (compareDurableVersions(version, minimum) ?? -1) >= 0

export function getDurableCapabilities(version: string | null | undefined): DurableCapabilities {
  return {
    multipart: atLeast(version, '0.2.5'),
    transactionMode: atLeast(version, '0.2.5'),
    loopContinueOnFailure: atLeast(version, '0.2.8'),
  }
}
```

## Task 6 — Node tree

**Files:** create `D/Durable.tree.ts`, `D/Durable.tree.test.ts`

API:

```ts
export type DurableTreeNode = {
  id: string
  role: 'root' | 'step' | 'condition' | 'then' | 'else' | 'body' | 'branch'
  branchIndex?: number
  node: DurableNode | null // null = missing reference
  inLoop: boolean
  children: DurableTreeNode[]
}
export function buildNodeTree(
  rootId: string | null | undefined,
  nodes: DurableNode[]
): DurableTreeNode | null
export function parseExecutionGeneration(statusDetails: string | null): number | null
export function getNodeConfig(node: DurableNode): Record<string, unknown> | null // JSON.parse of query when object, else null
```

Rules:

- Root: `rootId` if it exists in `nodes`; otherwise the first node (by input order) whose id is
  not referenced by any `left_node`, `right_node`, `condition_node`, or `extra_nodes`. Empty
  input → `null`.
- `THEN`: flatten the right-leaning and left-leaning chain into one ordered list of `step`
  children (walk left subtree first, then right; any child that is itself `THEN` is expanded
  inline). The `THEN` node itself is kept as the parent row.
- `IF`: children `condition` (from config `condition_node`, if present), `then` (left), `else`
  (right). For `if_rows` config there is no condition child.
- `LOOP`: `body` (left), then `condition` (config `condition_node`). All descendants get
  `inLoop: true`.
- `JOIN` / `RACE`: `branch` children for left, right, then each `extra_nodes` id, numbered 1..n.
- Others: no children.
- Visited set: revisiting an id yields a `node: null` leaf instead of recursion. Missing ids
  also yield `node: null`.
- `parseExecutionGeneration`: parse JSON, read `execution_id`, return the last `::` token as an
  integer, or `null` on any failure.

condition/then/else; if_rows config has no condition child; LOOP body + condition with `inLoop`
propagated; JOIN with one extra produces 3 branches; root fallback when `rootId` is null; cycle
(a.left = b, b.left = a) terminates with a `node: null` leaf; dangling `right_node` yields a
`node: null` child; `parseExecutionGeneration('{"execution_id":"a1b2c3d4::1::7f9a0012::2"}') === 2`;
malformed JSON → `null`.

Build fixtures with a local `node(overrides)` helper returning a full `DurableNode` with nulls.

## Task 7 — Re-run reconstruction

**Files:** create `D/Durable.reconstruct.ts`, `D/Durable.reconstruct.test.ts`

API:

```ts
export type ReconstructResult = { expression: string } | { error: string }
export function reconstructExpression(
  rootId: string | null | undefined,
  nodes: DurableNode[]
): ReconstructResult
```

Implementation:

- Index nodes by id. Resolve root like `buildNodeTree` (reuse a shared `findRootId` exported
  from `Durable.tree.ts`).
- Recursive `emit(id, visiting: Set<string>): SafeSqlFragment`, throwing an internal
  `ReconstructError` with a short English reason; the public function catches and returns
  `{ error }` (reasons are wrapped with `$t` at the UI layer, not here).
- Use `safeSql` + `literal` so escaping is identical to the builder. JSON values:
  `safeSql\`${literal(JSON.stringify(value))}::jsonb\``.
- Per node type (see "Verified 0.2.8 facts"): emit exactly as the spec table. Details:
  - `SQL`: `df.sql(${literal(query)})`; missing query → error.
  - `SLEEP`: `query` must match `/^\d+$/` → `df.sleep(${literal(Number(q))}::bigint)`.
  - `SIGNAL`: `timeout_seconds` null → one-arg form, else `, n::integer`.
  - `HTTP`: `df.http(url, method, body|NULL, headers::jsonb|NULL, timeout)`; when
    `timeout_seconds` is null pass `30`.
  - `HTTP_MULTIPART`: same with `parts::jsonb`.
  - `BREAK`: `break_value` null → `df.break()`, else `df.break(${literal(v)})`.
  - `IF`: if config `condition_type === 'result_has_rows'` →
    `df.if_rows(${literal(result_name)}, then, else)`; else requires `condition_node` →
    `df.if(cond, then, else)`. Both arms required.
  - `LOOP`: body required; append `, cond` when `condition_node`; append
    `, continue_on_failure => true` when config `continue_on_failure === true`.
  - `JOIN`: fold `df.join` over `[left, right, ...extra_nodes]`. `RACE`: `df.race(l, r)`.
  - `THEN`: `df.seq(l, r)`.
  - Unknown type, missing child, non-object config where one is required, or a cycle → error.
- Wrap with `df.as(expr, ${literal(result_name)})` when `result_name` is set.

Tests (first), with node fixtures shaped exactly like 0.2.8 rows:

- One fixture per node type, asserting the exact expression string.
- Round-trip: for builder outputs of Task 5 (`loop` with condition + continue_on_failure,
  `if` with both arms, `if_rows`, 3-way `race`, `parallel` with `resultName`), hand-write the
  equivalent node rows and assert `reconstructExpression` equals the `buildStep` string, except
  that builder `df.if` passes the condition as a literal string while reconstruction emits
  `df.sql('...')` for the condition node — assert both forms explicitly rather than equality
  for that case.
